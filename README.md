# Generative AI - Gemini Chatbot

## Description
This is a simple AI chatbot developed using Google Gemini API and Google Colab.

## Technologies Used
- Python
- Google Colab
- Google Gemini API
- Generative AI

## Features
- Generates AI-based responses
- Uses Gemini Generative AI model
- Simple and easy to use

## Example
The chatbot can suggest books for a new book shop.

Example prompt:

"I want to open a Book Shop. Suggest Some Books for it."
